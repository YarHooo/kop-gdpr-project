# Privacy Policy

## Introduction
This project respects user privacy and follows GDPR principles.

## Data Collection
The application may store cookie consent preferences in the browser localStorage.

No personal data is collected, shared, or sold.

## Cookies
The application uses cookies/local storage only for:
- Necessary functionality
- Saving user cookie preferences

## User Rights
Users can:
- Accept or reject cookies
- Clear browser storage at any time
- Withdraw consent

## GDPR Compliance
This project provides:
- Cookie consent popup
- Consent configuration
- Transparency about stored data
